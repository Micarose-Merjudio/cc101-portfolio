## Sample Pseudocode: Decimal to Binary

```
START
    INPUT Decimal_number
    SET Binary_string = ''
    SET N = Decimal_number
    WHILE N > 0 DO
        SET R = N MOD 2
        SET Binary_string = String(R) + Binary_string
        SET N = N DIV 2
    ENDWHILE
    DISPLAY Binary_string
END
```
